# Money Planner

Money Planner is a browser-based budgeting dashboard for tracking expenses, planning bills and following savings goals. It is designed for people who want a visual overview without connecting a bank account.

- [Open Money Planner](https://samiraabdi3344.github.io/money-planner/)
- [View the repository](https://github.com/samiraabdi3344/money-planner)

## Features

- Monthly, weekly and fortnightly planning periods with previous and next navigation
- Income and expense tracking, transaction history, search and filters
- Category budgets, flexible allocations, recurring monthly bills and savings goals
- Subscription and debt tracking, financial calculators and data-backed charts
- Six-month schedule-based forecasts with recurring income
- Ten colour themes and responsive layouts
- JSON backups, restoration and transaction CSV import and export

## Getting started

Visit the live site and choose sample data or a blank dashboard. Set a monthly spending budget, then add transactions, bills and goals. Use the planning-period controls to navigate between periods.
